- VMware Workstation with the Kali Linux and Windows 10 x64 VM tabs.
- A Kali-side demonstration workflow using Metasploit tooling.
- A logistics/shipping-invoice-themed phishing email scenario.
- A custom Windows-side PoC screen that illustrates simulated file-encryption and system-lockdown behavior.

## Evidence boundary

This is an educational lab PoC, not Qilin's original ransomware and not a reproduction of the Asahi production environment. The video does not preserve enough information to establish the original VM CPU/RAM allocation, VMnet mode, IP addressing, VLAN IDs, firewall rules, central logging, or backup configuration.

The demo video is linked from the original Google Drive location rather than duplicated into Git history as a large binary file. Access depends on the Drive sharing permission.

## Safety

Use only in a disposable, isolated lab that you own or are authorized to test. Do not execute payloads on production systems or third-party networks. Revert to a clean baseline after an exercise.
