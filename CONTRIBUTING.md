# Contributing

Thank you for your interest in this project! This repository is primarily an **archived academic case study** and is not actively maintained for feature development.

## How You Can Contribute

### 🐛 Bug Reports & Corrections
If you find factual errors, broken links, or outdated information:
1. Open an [Issue](../../issues) describing the problem
2. Reference the specific file and line number
3. Provide the correct information with sources

### 📝 Documentation Improvements
- Spelling/grammar fixes
- Translation improvements (Vietnamese ↔ English)
- Additional MITRE ATT&CK technique mappings
- Updated threat intelligence references

### 🔬 Technical Additions
- Additional lab simulation scenarios (must be in isolated environments)
- Alternative defense-in-depth proposals
- Incident response playbook templates
- Detection rule examples (YARA, Sigma, Snort)

## Guidelines

1. **Educational Purpose Only:** All contributions must be for educational and defensive security research
2. **No Malicious Code:** Do not submit actual malware, exploits, or attack tools
3. **Cite Sources:** Reference official reports, CVEs, and threat intelligence sources
4. **Respect Privacy:** Do not include PII or sensitive corporate information

## Code of Conduct

Be respectful, constructive, and focused on improving cybersecurity education.
