# Project Report

**[Open Asahi Brewery Cyberattack — Project Report](https://docs.google.com/document/d/1aTacFKg4T68DmGAslC-MS-hgPeNJAvHQ/edit)**

## Public sharing and privacy

The source report cover includes the names and student identification numbers of the project contributors. Before changing the Google Docs link to public viewer access, obtain the contributors' consent. This repository does not duplicate the unredacted DOCX in public Git history.
